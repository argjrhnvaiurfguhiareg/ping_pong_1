# ping_pong_1
# 🏓 Retro Terminal Pong (Static & Dynamic Versions)

Консольный пинг-понг на языке C, реализованный в двух архитектурных вариантах. Это учебно-демонстрационный проект. Здесь важны не только сама игра, но и работа с состоянием терминала, низкоуровневый ввод/вывод в Unix-системах, автоматизация сборки через Makefile и базовый игровой ИИ.

## 🎮 Две версии игры
Проект специально разделён на две независимые версии, и у каждой своя архитектурная задача.

1) **Статическая (пошаговая) версия:** 

- Использует только стандартные библиотеки `<stdio.h>` и `<unistd.h>`. Никаких платформозависимых или внешних зависимостей.

- Игра идёт в пошаговом режиме. Кадр обновляется и мяч делает шаг только после действия одного из игроков и нажатия Enter.

- Реализована очистка и фильтрация входного потока `stdin`. Это не даёт зажатым клавишам вроде aaaaa наслаиваться и не оставляет мусор на экране.

2) **Динамическая версия на ncurses:**

- Использует библиотеку `ncurses` и работает как полноценный игровой движок в реальном времени.

- Игра идёт сама со скоростью около 25 FPS. Ракетки двигаются плавно и сразу, без необходимости нажимать Enter.

- Применяются `cbreak()`, `noecho()` и неблокирующий ввод с помощью `nodelay()`. Отрисовка идёт через двойной буфер (`erase()` / `refresh()`), поэтому мерцание экрана отсутствует. Элементы интерфейса раскрашены отдельными цветовыми палитрами.

- Есть одиночный режим против бота. Бот оценивает траекторию мяча, возвращается на тактическую позицию в центр поля и имеет заложенный процент человеческих ошибок — точность около 85%, а это делает матчи азартнее.

## 🛠️ Управление в игре
* `A` / `a` — движение левой ракетки (Игрок 1) **вверх**
* `Z` / `z` — движение левой ракетки (Игрок 1) **вниз**
* `K` / `k` — движение правой ракетки **вверх** *(только в статической версии для 2 игроков)*
* `M` / `m` — движение правой ракетки **вниз** *(только в статической версии для 2 игроков)*
`Пробел` — выход из игры

*Матч идёт до **21 очка**.*

## 🚀 Автоматизация сборки и запуск
Сборка проекта полностью автоматизирована через `Makefile`. При компиляции автоматически создаётся папка build/, куда помещаются готовые бинарные файлы.

Для динамической версии нужно, чтобы в системе была установлена библиотека ncurses. В Ubuntu/Debian:
sudo apt install libncurses5-dev

### Сборка проекта
Чтобы собрать обе версии, выполните:
```make pong_build```

### Запуск
После успешной сборки исполняемые файлы появятся в директории `build/`. Запустить их можно так:

Статическая версия:
```./build/pong_static```

Динамическая версия — с графикой и ИИ:
```./build/pong_dynamic```

## 🧠 Технический стек и навыки:

- **Язык:** C (C99)

- **Утилиты:** GNU Make для автоматизации компиляции, создания директорий, линковки зависимостей.

- **Основные концепции:** потоки ввода/вывода, ANSI-управляющие последовательности, маскирование сигналов терминала, Game Loop, неблокирующий опрос клавиатуры, работа со структурами памяти ncurses, симуляция поведения ИИ на основе псевдослучайных чисел (rand()).
